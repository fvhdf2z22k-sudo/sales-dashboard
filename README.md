# 공개 매출 대시보드

웹페이지 코드는 이 저장소에서 무료 GitHub Pages로 배포합니다. 누구나 URL에서 같은 공개 자료를 볼 수 있고, 원본 자료 변경 권한은 이 GitHub 저장소에 쓰기 권한이 있는 계정에만 있습니다. 별도 Supabase·로그인 서버·관리자 토큰을 사용하지 않습니다.

## 최초 한 번: 사이트 켜기

1. 저장소 **Settings → Pages**로 이동합니다.
2. Source: **Deploy from a branch**
3. Branch: **main**, Folder: **/ (root)** 선택 후 **Save**
4. 배포가 완료되면 https://fvhdf2z22k-sudo.github.io/sales-dashboard/ 에 접속합니다.

`index.html`은 공개 조회용, `editor.html`은 이 브라우저 안에서만 자료를 편집하는 도구입니다. 편집 화면을 여는 것만으로는 서버 자료를 바꿀 수 없습니다. 실제 공개 자료를 바꾸려면 본인 GitHub 계정으로 `data/public.json` 파일을 교체해야 합니다. 다른 사람은 화면에서 필터·보고서를 조절하거나 자기 브라우저에 초안을 만들 수 있지만, 이 저장소에 쓰기 권한이 없으면 공개 자료를 바꿀 수 없습니다.

## 자료를 처음 올리거나 업데이트하기

1. **자료 업데이트 준비**를 엽니다.
2. **기존 JSON 백업 불러오기**로 기존 대시보드 백업을 복원하거나, 매출 파일·내부 카테현황을 입력합니다.
3. 분석 결과를 확인하고 상단 **공개 자료용 JSON 다운로드**를 누릅니다.
4. 내려받은 파일 이름이 `public.json`인지 확인합니다. 브라우저가 `public (1).json` 등으로 이름을 바꿨다면 `public.json`으로 바꿉니다.
5. **GitHub에 JSON 올리기**를 누릅니다. [data 폴더 업로드](https://github.com/fvhdf2z22k-sudo/sales-dashboard/upload/main/data)에서 본인 계정으로 로그인한 뒤 `public.json`을 올리고 **Commit changes**를 누릅니다. 반드시 기존 **data/public.json**을 교체해야 합니다.
6. GitHub 배포가 끝나면 공개 페이지의 **최신 자료 새로고침**을 누릅니다. 다른 컴퓨터에서도 같은 자료가 나옵니다. 조회 화면은 열려 있는 동안 약 1분 간격으로도 변경을 확인합니다.

편집·JSON 다운로드만으로는 공개 자료가 바뀌지 않습니다. 브라우저 초안이 오래됐다면 **공개 자료로 다시 시작**으로 최신 자료를 불러온 뒤 수정하세요. 여러 컴퓨터에서 동시에 수정하면 마지막에 GitHub에 올린 파일로 교체됩니다. 이전 공개 버전은 GitHub 파일 이력에서 확인할 수 있습니다.

## 공개 범위

처음에는 빈 JSON만 들어 있습니다. 실제 매출 자료는 기본으로 포함하지 않았습니다. `data/public.json`으로 올린 전체 파일 분석 행·파일 목록·내부 카테현황은 누구나 다운로드할 수 있고, Git 기록에도 남을 수 있습니다. 화면의 특정 채널 필터를 선택해도 JSON 전체가 공개됩니다. 공유하지 않을 자료는 올리지 마세요. 기존 매출 데이터가 들어 있는 비공개 저장소를 공개로 바꿀 필요는 없습니다.

매출 업로드·편집은 브라우저에서 처리하며 사이트가 GitHub에 자동으로 쓰지 않습니다. GitHub 쓰기는 소유자가 GitHub 웹 화면에서 직접 합니다. 앱에 비밀번호나 GitHub 토큰을 입력할 필요가 없습니다.

## 시즌상품 분석

시즌상품 탭에서 여름·겨울·여름/겨울 혼합·전체 시즌상품 실적을 조회할 수 있습니다. 상단 채널·중분류·소분류·기간·동일 요일/날짜 기준을 반영합니다. 기본 범위는 침구 소분류이며, 침구/커튼/카페트 전체로 넓힐 수 있습니다. 상단에서 침실가구 등을 선택해 자료가 보이지 않으면 '상단 필터를 침구 전체로'를 누르세요.

- 여름 키워드: 냉감, 쿨, 시어서커, 여름
- 겨울 키워드: 구스, 극세사, 겨울, 울, 양모
- 울은 겨울·서울·방울·거울·저울·울트라·울산·울릉·울타리 속의 문자를 제외합니다.

상품명 기준 분류이며 판매월로 나누지 않습니다. 두 시즌 키워드가 함께 있으면 혼합으로 분리합니다. 여름/겨울 선택에는 혼합 상품을 포함하지 않으며, 전체 시즌상품은 혼합을 한 번만 포함합니다. 미일치 상품도 별도 행으로 표시해 여름·겨울·혼합·미일치 합계가 분석 범위 전체와 일치하게 합니다. 음수 조정 행도 제외하지 않습니다.

선택 시즌의 매출·판매량·평균 판매단가·매출 비중, 전년 대비 변화, 일별 매출, 브랜드·쇼핑몰·상품별 실적과 매칭 키워드를 표시합니다. 상단 현재 표 CSV는 선택 시즌의 상품별 비교 전체를 내려받습니다. 키워드별 표는 한 상품이 여러 키워드에 매칭될 수 있어 행을 서로 더하면 안 됩니다.

같은 상품이더라도 연도별 이름이나 키워드가 바뀌면 시즌 안에서의 증감은 전체 상품 매출 증감과 다를 수 있습니다. 해당 시즌에서 전년 판매가 없는 것은 신규 출시를 의미하지 않습니다. 키워드 매칭은 실제 소재·용도를 확정하지 않으므로 상품 이름과 매칭 단어를 함께 확인하세요.

기존 JSON은 그대로 사용할 수 있습니다. 키워드 분류는 브라우저에서 계산하며 업로드 자료나 공개 JSON 형식을 변경하지 않습니다. 합계 대사·중복 방지·울 오탐 방지·분석 범위·음수 매출·16개 시즌/범위/비교 모드 조합·일별 그래프 및 상품 CSV 합계·실제 공개 자료와 기존 분석 화면을 검증했습니다. 테스트는 Playwright 및 Chromium이 있는 환경에서 `python tests/test_season.py`로 실행합니다.

## 분석 기능

동일 요일/동일 날짜 비교, 중·소분류 필터, 쇼핑몰·상품 분석, 신상품·집중도, 분류별 보고서·동일 상품명 단가/수량/매출 분석, 내부 전년·당년 카테현황을 제공합니다. 내부 카테현황은 입력한 내부 자료끼리만 비교합니다. 가격·판매량의 동반 변화는 인과관계를 확정하지 않습니다.
